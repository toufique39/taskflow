# TaskFlow – AI Productivity & Task Management

TaskFlow is a modern SaaS landing page for an AI-powered productivity and task management platform. It helps students, freelancers, and teams organize tasks, manage projects, and improve productivity.

## Features

- Modern and responsive landing page
- Responsive navigation with mobile menu
- Hero section with dashboard preview
- Features showcase
- About and How It Works sections
- Free and Pro pricing plans
- Contact form with validation and success message
- Responsive footer

## Technologies Used

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Lucide React

## Installation

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

4. Build for production:

   `npm run build`
